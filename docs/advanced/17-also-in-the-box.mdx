Smaller features worth knowing about before you need them.

| Topic | In one line | Read |
| --- | --- | --- |
| Sessions and SSO | A session belongs to one flow, so apps on the same flow share sign-in and apps on different flows never do. A Check SSO Session node and a Save / Load Session node mark the steps a session can skip. | [Sessions](https://thunderid.dev/docs/next/key-concepts/authentication/sessions), [SSO for flows](https://thunderid.dev/docs/next/guides/flows/single-sign-on) |
| Logout | RP-initiated logout ends the session from the app. Back-channel logout notifies other apps' servers. | [RP-initiated](https://thunderid.dev/docs/next/guides/protocols/oauth-oidc/rp-initiated-logout), [Back-channel](https://thunderid.dev/docs/next/guides/protocols/oauth-oidc/backchannel-logout) |
| Consent | A User Consent step in the flow asks the user to approve attributes, permissions and authorization details. The token carries only what they approve. | [Consent](https://thunderid.dev/docs/next/guides/consent) |
| Account protection | A lock forms after repeated failed attempts. A suspension is an admin's decision that also revokes existing sessions and tokens. | [Account protection](https://thunderid.dev/docs/next/guides/account-protection/overview) |
| Design | Themes (colours, typography) and layouts (screen structure) style Gate's screens, independently of each other. | [Design](https://thunderid.dev/docs/next/guides/design/overview) |
| Localization | Every screen string is a language + namespace + key, overridable per deployment. | [Localization](https://thunderid.dev/docs/next/guides/i18n/localization) |
| Observability | Structured events for token issuance, flow execution and authorization decisions, sent to console, file or OpenTelemetry. Off by default. | [Observability](https://thunderid.dev/docs/next/deployment/observability) |
| ThunderID MCP server | `/mcp` lets an AI coding assistant manage applications and flows, behind OAuth with system permissions. | [MCP server](https://thunderid.dev/docs/next/working-with-ai/mcp-server) |
| Agent skills | Skills and Claude / Codex plugins that set up ThunderID and wire auth into an app from a prompt. | [Skills](https://thunderid.dev/docs/next/working-with-ai/skills) |
| Deployment | Docker, Kubernetes (Helm) and OpenChoreo paths, with production guidelines. | [Deployment paths](https://thunderid.dev/docs/next/deployment/deployment-paths), [Production guidelines](https://thunderid.dev/docs/next/deployment/production-guidelines) |
